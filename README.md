# هفت‌خوان (HaftKhan)

بازی کارتی فارسی با رابط مشکی و فیروزه‌ای، شامل حکم چهارنفره و هفت‌خبیث. هدف پروژه تجربه‌ای آفلاین و قابل استفاده روی وب و اندروید است.

## وضعیت واقعی پروژه

- [x] مخزن GitHub و مستندات پایه
- [x] پوسته اولیه واکنش‌گرای وب
- [x] صفحه اولیه Expo برای اندروید
- [x] موتور پایه کارت، بُر زدن و پخش کارت
- [x] منطق پایه یک دست حکم و دنبال‌کردن خال
- [x] تنظیمات قابل تغییر قوانین حرکت هفت‌خبیث در موتور
- [x] تست‌های واحد اولیه برای قوانین کارت
- [x] میز حکم قابل‌بازی اولیه در وب و اندروید
- [ ] ربات‌های استراتژیک با سطح دشواری
- [ ] تکمیل چرخه کامل امتیازدهی و پایان بازی حکم
- [ ] پیاده‌سازی اثرات اجرایی کارت‌های ویژه هفت‌خبیث
- [ ] ۱۰ مجموعه تصویر نهایی کارت با الهام از هنرهای ایرانی
- [ ] ذخیره محلی، تنظیمات و آمار
- [ ] تکمیل تست CI پس از اتصال رابط اندروید و ساخت وب
- [ ] ساخت و تست APK/AAB روی دستگاه واقعی
- [ ] انتشار نسخه وب و انتشار اندروید

## فناوری

- وب: React، Vite و TypeScript
- اندروید: React Native و Expo
- موتور مشترک: TypeScript و Vitest

## توسعه محلی

نیازمند Node.js 20 یا جدیدتر:

```bash
npm install
npm run dev
npm run typecheck
npm test
npm run build
```

این مخزن هنوز نسخه انتشار نهایی نیست. برای انتشار باید CI واقعاً سبز شود، بازی در هر دو رابط اجرا و تست شود و خروجی اندروید ساخته و روی دستگاه بررسی شود.
