# هفت‌خوان (HaftKhan)

بازی کارتی فارسی با رابط مشکی و فیروزه‌ای؛ شامل حکم چهارنفره و هفت‌خبیث. این پروژه برای اجرای آفلاین در وب و اندروید ساخته می‌شود.

## قابلیت‌های پیاده‌سازی‌شده

- [x] مخزن و گردش‌کار بررسی خودکار در GitHub Actions
- [x] رابط واکنش‌گرای فارسی برای وب و رابط Expo اندروید
- [x] موتور مشترک TypeScript برای هر دو بازی
- [x] حکم آفلاین: ۵۲ کارت، چهار دست ۱۳ کارتی، دنبال‌کردن خال، خال حکم، ثبت برنده هر دست و پایان دور با رسیدن تیم به ۷ دست
- [x] ربات‌های پایه برای بازی آفلاین حکم
- [x] هفت‌خبیث آفلاین: ۷ کارت برای هر بازیکن، کارت‌کشیدن، سرباز برای تغییر خال، آس برای تغییر جهت، هشت برای رد نوبت و هفت برای انباشتن جریمه
- [x] تنظیمات قوانین ویژه هفت‌خبیث در موتور بازی
- [x] ۱۰ طرح برداری اختصاصی کارت با الهام از نقش‌مایه‌های ایرانی در `apps/web/src/assets/card-art/`
- [x] انتخاب طرح کارت در پیش‌نمایش وب
- [x] تست‌های واحد برای توزیع کارت‌ها، حرکت قانونی، نوبت‌ها و منطق پایه هر دو بازی
- [x] گردش‌کار ساخت وب و انتشار خودکار GitHub Pages
- [x] گردش‌کار دستی ساخت APK اندروید

## کارهای باقی‌مانده برای انتشار عمومی

- [ ] تأیید سبز بودن CI برای آخرین commit
- [ ] تأیید موفق اجرای انتشار Pages و بازشدن سایت نهایی
- [ ] اجرای گردش‌کار APK، دریافت فایل خروجی و آزمایش روی دستگاه واقعی
- [ ] بررسی نهایی تجربه فارسی/انگلیسی، دسترس‌پذیری و اندازه صفحه روی چند دستگاه
- [ ] افزایش سطح راهبردی ربات‌ها؛ فعلاً ربات‌ها حرکت‌های قانونی را انتخاب می‌کنند و هوش رقابتی پیشرفته ندارند
- [ ] تکمیل تست‌های سناریوهای خاص و قوانین محلی هفت‌خبیث
- [ ] بازبینی امنیتی وابستگی‌ها و ارتقای نسخه‌های قدیمی Expo/React Native
- [ ] ذخیره دائمی تنظیمات، آمار و تاریخچه بازی
- [ ] انتشار نسخه نهایی با نسخه‌بندی و یادداشت انتشار

## فناوری

- وب: React، Vite، TypeScript و CSS
- اندروید: React Native و Expo
- موتور مشترک: TypeScript و Vitest
- CI و انتشار وب: GitHub Actions و GitHub Pages

## توسعه محلی

نیازمند Node.js 20 یا جدیدتر:

```bash
npm install
npm run dev
npm run typecheck
npm test
npm run build
```

## وضعیت انتشار

این مخزن اکنون میزهای قابل‌بازی اولیه برای هر دو بازی دارد؛ اما تا زمان سبزشدن آخرین CI، انتشار موفق Pages و ساخت و آزمایش APK، نباید آن را نسخه نهایی انتشار عمومی دانست.
