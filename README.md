# هفت‌خوان (HaftKhan)

مجموعه بازی کارتی فارسی با رابط کنسولی مشکی و فیروزه‌ای؛ شامل صفحه‌های مستقل حکم، هفت‌خبیث و چهاربرگ. پروژه برای اجرای آفلاین در وب و اندروید ساخته می‌شود.

## قابلیت‌های پیاده‌سازی‌شده

- [x] مخزن و گردش‌کار بررسی خودکار در GitHub Actions
- [x] رابط واکنش‌گرای فارسی و راست‌به‌چپ برای وب و رابط Expo اندروید
- [x] صفحه مستقل برای هر یک از سه بازی در وب، همراه با نوار جابه‌جایی بین میزها
- [x] پیمایش صفحه‌های وب با کلیدهای جهت، تأیید با Enter و بازگشت با Escape؛ نگاشت اولیه دکمه‌های دسته از طریق Gamepad API
- [x] میز اولیه چهاربرگ در وب با ربات آفلاین، کارت‌گیری و امتیاز پایه
- [x] موتور مشترک TypeScript برای هر دو بازی
- [x] حکم آفلاین: ۵۲ کارت، چهار دست ۱۳ کارتی، دنبال‌کردن خال، خال حکم، ثبت برنده هر دست و پایان دور با رسیدن تیم به ۷ دست
- [x] ربات‌های پایه برای بازی آفلاین حکم
- [x] چهاربرگ آفلاین در وب: جمع‌آوری کارت هم‌رتبه یا ترکیب با مجموع ۱۱، کارت‌گیری مرحله‌ای، ربات پایه و امتیازهای استاندارد پایه؛ قوانین موتور و امتیازدهی تست واحد دارند
- [x] ذخیره‌ی محلی تاریخچه‌ی ۱۲ نتیجه‌ی اخیر سه بازی در وب
- [x] پرونده‌ی بازیکن با آمار برد، باخت و مساوی روی همان دستگاه
- [x] سه درجه‌ی سختی ربات در میزهای وب؛ سطح راهبردی حکم و اولویت‌های متفاوت در هفت‌خبیث و چهاربرگ
- [x] بهبود فوکوس کیبورد/دسته، نشانگر اتصال دسته، انیمیشن ظریف کارت و رعایت کاهش حرکت
- [x] حالت دونفره‌ی نوبتی روی یک دستگاه برای چهاربرگ
- [x] واگذاری کارت‌های باقی‌مانده‌ی میز به آخرین بازیکن جمع‌کننده در چهاربرگ
- [x] هفت‌خبیث آفلاین: ۷ کارت برای هر بازیکن، کارت‌کشیدن، سرباز برای تغییر خال، آس برای تغییر جهت، هشت برای رد نوبت و هفت برای انباشتن جریمه
- [x] تنظیمات قوانین ویژه هفت‌خبیث در موتور بازی
- [x] ۱۰ طرح برداری اختصاصی کارت با الهام از نقش‌مایه‌های ایرانی در `apps/web/src/assets/card-art/`
- [x] انتخاب و ذخیره محلی تم و طرح کارت در وب
- [x] ذخیره محلی تم و شمارنده دورهای تکمیل‌شده در اندروید
- [x] فونت فارسی محلی برای وب و جهت سند فارسی/راست‌به‌چپ
- [x] انتخاب تم و ثبت آمار دورهای تکمیل‌شده در وب
- [x] تست‌های واحد برای توزیع کارت‌ها، حرکت قانونی، نوبت‌ها و منطق پایه هر دو بازی
- [x] گردش‌کار ساخت وب و انتشار خودکار GitHub Pages
- [x] گردش‌کار دستی ساخت APK اندروید

## حریم خصوصی

این برنامه در نسخه فعلی بدون حساب کاربری طراحی شده و اطلاعات بازی و تنظیمات در حافظه محلی همان دستگاه ذخیره می‌شوند. هیچ سرویس تحلیلی یا جمع‌آوری حساب کاربری عمداً اضافه نشده است. این توضیح با بررسی وابستگی‌ها و رفتار نسخه نهایی باید پیش از انتشار عمومی دوباره تأیید شود. سیاست کامل در [`PRIVACY.md`](./PRIVACY.md) آمده است.

## فناوری

- وب: React، Vite، TypeScript و CSS
- اندروید: React Native و Expo
- موتور مشترک: TypeScript و Vitest
- CI و انتشار وب: GitHub Actions و GitHub Pages

## توسعه محلی

نیازمند Node.js 20 یا جدیدتر:

```bash
npm install
npm run dev
npm run typecheck
npm test
npm run build
```

## وضعیت انتشار

این مخزن اکنون میزهای قابل‌بازی اولیه برای هر دو بازی دارد؛ اما تا زمان سبزشدن آخرین CI، انتشار موفق Pages و ساخت و آزمایش APK، نباید آن را نسخه نهایی انتشار عمومی دانست.
