# HaftKhan — بازی کارتی ایرانی

بازی کارتی فارسی با تم مشکی و فیروزه‌ای؛ شامل حکم چهارنفره و هفت‌خبیث، ربات‌های آفلاین و ۱۰ مجموعه کارت با الهام از هنرهای محلی ایران.

## وضعیت فعلی
- [x] ساخت مخزن و مستندات اولیه
- [x] پوسته وب واکنش‌گرا با TypeScript
- [x] پایه موتور مشترک کارت و توزیع کارت
- [ ] تکمیل قوانین حکم و تست‌های آن
- [ ] تکمیل قوانین قابل تنظیم هفت‌خبیث
- [ ] ربات‌های سطح‌بندی‌شده
- [ ] اپلیکیشن Android با Expo
- [ ] ۱۰ مجموعه گرافیکی نهایی کارت
- [ ] ساخت و تست خروجی انتشار

## فناوری
- Web: React, Vite, TypeScript
- Android: React Native + Expo (مرحله بعد)
- Shared engine: TypeScript

## توسعه وب
```bash
npm install
npm run dev
```

> این مخزن در حال توسعه است؛ تا زمان تکمیل تست‌ها و ساخت APK، نسخه انتشار نهایی محسوب نمی‌شود.
