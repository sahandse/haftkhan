# هفت‌خوان (HaftKhan)

مجموعه بازی کارتی فارسی با رابط مشکی و فیروزه‌ای؛ شامل صفحه‌های مستقل حکم، هفت‌خبیث و چهاربرگ. بازی‌های آفلاین در وب و اندروید قابل استفاده‌اند؛ بازی آنلاین فعلاً فقط برای چهاربرگ به‌صورت آزمایشی پیاده‌سازی شده است.

## قابلیت‌های پیاده‌سازی‌شده

- [x] رابط واکنش‌گرای فارسی و راست‌به‌چپ برای وب و رابط Expo اندروید
- [x] صفحه مستقل برای حکم، هفت‌خبیث و چهاربرگ در وب
- [x] پیمایش صفحه‌های وب با کلیدهای جهت، Enter و Escape؛ پشتیبانی اولیه از Gamepad API
- [x] حکم آفلاین با دسته ۵۲ کارتی، چهار دست ۱۳ کارتی، دنبال‌کردن خال و ثبت برنده هر دست
- [x] چهاربرگ آفلاین با جمع‌آوری کارت هم‌رتبه یا ترکیب با مجموع ۱۱، کارت‌گیری مرحله‌ای و امتیاز پایه
- [x] هفت‌خبیث آفلاین با کارت‌کشیدن و اثرهای پایه کارت‌های ویژه
- [x] موتور مشترک TypeScript و تست‌های واحد برای منطق پایه بازی‌ها
- [x] ربات‌های آفلاین و درجه‌های مختلف سختی
- [x] حالت دونفره نوبتی روی یک دستگاه برای چهاربرگ
- [x] تاریخچه محلی نتایج، آمار بازیکن، تم و طرح کارت
- [x] ۱۰ طرح برداری کارت با الهام از نقش‌مایه‌های ایرانی
- [x] فونت فارسی محلی، چیدمان RTL، فوکوس صفحه‌کلید و رعایت کاهش حرکت
- [x] گردش‌کار خودکار بررسی، تست و ساخت وب در GitHub Actions
- [x] گردش‌کار ساخت APK اندروید در GitHub Actions
- [x] اتاق آزمایشی آنلاین چهاربرگ با کد عددی ۴ رقمی و حداکثر ۴ بازیکن

## بازی آنلاین چهاربرگ

یک نفر اتاق می‌سازد و کد عددی ۴ رقمی می‌گیرد؛ سه نفر دیگر با کد وارد می‌شوند و بازی پس از ورود هر چهار نفر شروع می‌شود.

برای فعال‌کردن اتصال واقعی:
1. در Supabase یک پروژه بساز.
2. در مخزن GitHub از مسیر **Settings → Secrets and variables → Actions → Variables** دو متغیر زیر را ایجاد کن:
   - `VITE_SUPABASE_URL`: نشانی پروژه Supabase
   - `VITE_SUPABASE_ANON_KEY`: کلید عمومی `anon` پروژه
3. گردش‌کار Pages را دوباره اجرا کن یا یک commit جدید به شاخه `main` بفرست.

این مقادیر عمومی در خروجی مرورگر قابل مشاهده‌اند؛ فقط کلید عمومی `anon` را استفاده کن و هرگز کلید `service_role` یا کلید محرمانه را در کد یا متغیرهای `VITE_*` قرار نده.

**محدودیت مهم:** کانال‌های آنلاین فعلی عمومی و بدون احراز هویت هستند؛ این نسخه نمونه اولیه برای بازی دوستانه است، نه سرویس مقاوم در برابر تقلب یا دسترسی غیرمجاز. همچنین تا زمانی که متغیرهای Supabase ثبت و بازی بین چند دستگاه آزمایش نشود، اتصال آنلاین آماده و تأییدشده محسوب نمی‌شود. اگر متغیرها تنظیم نشده باشند، بازی‌های آفلاین همچنان قابل استفاده‌اند اما اتاق آنلاین کار نمی‌کند.

## حریم خصوصی

برنامه در نسخه فعلی حساب کاربری ندارد و آمار و تنظیمات محلی روی همان دستگاه نگهداری می‌شوند. حالت آنلاین چهاربرگ از Supabase Realtime استفاده می‌کند و اطلاعات لازم برای اتاق و بازی را از طریق کانال آنلاین مبادله می‌کند. جزئیات در [سیاست حریم خصوصی](./PRIVACY.md) آمده است.

## فناوری

- وب: React، Vite، TypeScript و CSS
- اندروید: React Native و Expo
- موتور مشترک: TypeScript و Vitest
- ساخت و انتشار: GitHub Actions و GitHub Pages
- ارتباط آزمایشی آنلاین: Supabase Realtime

## توسعه محلی

نیازمند Node.js 20 یا جدیدتر:

```bash
npm install
npm run dev
npm run typecheck
npm test
npm run build
```

- طراحی کنترل دسترسی و اعتبارسنجی امن سمت سرور برای نسخه آنلاین عمومی
- بررسی حریم خصوصی و جلوگیری از افشای اطلاعات دست بازیکنان به سایر بازیکنان
- آزمایش APK روی چند گوشی و اندازه صفحه
- تکمیل تست قوانین محلی هفت‌خبیث، سناریوهای خاص و شبیه‌سازی ربات‌ها
- بررسی دسترس‌پذیری، زبان انگلیسی و وابستگی‌ها
- تصمیم درباره اضافه‌کردن حالت دونفره محلی به حکم و هفت‌خبیث و آنلاین‌کردن آن‌ها
- انتشار نسخه نهایی با شماره نسخه و یادداشت انتشار
